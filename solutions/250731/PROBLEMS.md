## C. Contest Reactions

[题目入口](https://codeforces.com/gym/105631/problem/C) · [c.cpp](c.cpp)

给 k+1 支队伍的 n 条按时间顺序排列的提交日志（队伍编号 0..k、题号 A..Z、结果 AC/RJ），每当 0 号队伍首次通过一道新题，输出该提交时间、题号和通过前后的排名，排名不变也要输出。排名先比较解题数（多者优先），再比较罚时（少者优先），完全相同则并列。每道通过的题贡献首次 AC 的整分钟数及此前每次 RJ 的 20 分钟罚时。
k≤10^5，n≤2×10^5。输出格式为 hh:mm:ss.SSS X #旧名次 -> #新名次。
代码：维护每队每题首次通过时间、失败次数，以及总罚时和通过题数。只在 0 号队伍首次通过某题时两次扫描所有队伍；由于至多 26 题，扫描次数至多 52 次，不需要动态排名树。
自拟例：两个队伍，1 号队 00:10 首过 A，0 号队 00:20 首过 B，0 号队排名从 2 到 2，仍输出这一行。

## L. LCM and GCD

[题目入口](https://codeforces.com/gym/105631/problem/L) · [l.cpp](l.cpp)

给正整数数组 a（n 项）和 b（m 项），构造 n×m 的正整数矩阵，使第 i 行的最小公倍数为 a_i、第 j 列的最大公因数为 b_j。矩阵元素及输入数值不超过 10^9，n,m≤1000；无解输出 No，有解输出 Yes 及任意合法矩阵。
代码：先检查所有 b_j 是否整除所有 a_i；单行时要求 lcm(b)=a_1，单列时要求 gcd(a)=b_1；一般情况试图在每列放一个 b_j，其余填该行 a_i。当 n,m≥2 时，令第 j 列的第 j mod n 行填 b_j（按 0 起始下标），其余填该行 a_i。每列有一个 b_j，每行至少有一个 a_i，所以在整除条件成立时构造正确。原代码未验证 AC。
自拟例：a=[6,12], b=[2,3]，可构造 [[2,6],[12,3]]。
